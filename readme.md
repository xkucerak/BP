## Usage of included scripts:

### [pytorch_exp.ipynb](pytorch_exp.ipynb)

Used for FP32 and FP16 onnx models export with dynamic input and output sizes. (Details for INT8 and INT4 quantization are located in the Scientific part.)

### [model_dump.ipynb](model_dump.ipynb)

Dumps weights of ONNX model/s to [model_dump](model_dump).

Extract weights from models currently from nodes:

| Data type  | Node name        |
| ---------- | ---------------- |
| FP32, FP16 | Conv, Gemm       |
| INT8       | DequantizeLinear |
| INT4       | Clip             |

And saves them in order generated by model.graph.node.

### [attack_prep.ipynb](attack_prep.ipynb)

Repacks weights generated above to 4MB chunks of binary data to [model_chunks](model_chunks).

### [attack.py](attack.py)

ChipSHOUTER and 3D printer control and corruption of data.

### [eval.py](eval.py)

Evaluates all original onnx models located in [models](models).

Currently measures TOP-1 and TOP-5 accuracy using torchmetrics and saves results to csv.

### [eval_intime.py](eval_intime.py)

Evaluates the ONNX model, replacing a 4MB chunk of weights in real time without saving new models.

### [cmp.ipynb](cmp.ipynb)

Visual comparison of data before and after the attack.

### [cmp_range.ipynb](cmp_range.ipynb)

Visualization of changes in weights by numerical distribution.

### [plot.ipynb](plot.ipynb)

Simple graphs of accuracy from csv files.
